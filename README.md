# DMF Knowledge Base

## Digital Monetary Framework — Fully-Backed Digital Currency

Welcome to the official Knowledge Base (KB) for the **Digital Monetary Framework (DMF)**, a protocol on the Base blockchain that issues **dmfUSD** — a fully-backed, non-custodial digital token. Every dmfUSD in circulation is fully backed by USDC held transparently in an immutable smart contract — with no peg, no debt, and backing that grows over time as protocol fees accumulate. No lending, no leverage, no admin mint, freeze, or pause — the only remaining owner power is setting the two operations-fee recipients.

This KB is the authoritative reference for understanding how DMF works, how to use it, and how to verify its integrity.
